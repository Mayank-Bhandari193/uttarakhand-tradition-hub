# Uttarakhand Tradition Hub - MERN Stack Project

Project based on YouTube Channel: `@pushpabhandari6645` (The Channel of Uttarakhand Tradition)

## Quick Start (Step-by-Step)

### Step 1: Extract Zip
Extract this zip file to your preferred folder.

### Step 2: Open in Visual Studio Code
Open VS Code -> `File` -> `Open Folder...` -> Select the extracted `uttarakhand-tradition-hub` folder.

### Step 3: Start the Backend Server
1. In VS Code, open a new Terminal (`Ctrl + \`` or `Terminal` -> `New Terminal`).
2. Run:
```bash
cd server
npm install
npm start
```
*Backend runs on http://localhost:5000*
*(Note: It includes automatic data fallback, so it runs smoothly even if local MongoDB service is not started!)*

### Step 4: Start the Frontend Client
1. Open a second Terminal tab in VS Code (`+` icon in terminal window).
2. Run:
```bash
cd client
npm install
npm run dev
```
*Frontend will run on http://localhost:5173*

### Step 5: Open in Browser
Visit `http://localhost:5173` in your browser.
